# Firefox Add-ons 商店资料（简体中文）

名称：哔哩哔哩 CDN 预热


简介：按播放进度预热后续视频片段，自定义提前量、请求时长与流量上限。

描述：

在哔哩哔哩观看视频时，自动请求稍后可能播放的视频片段，并按设定时长结束请求。扩展跟随播放器实际使用的视频流与 CDN，在跳转进度或切换视频流后重新安排预热。

- 根据播放进度、已缓冲范围和播放速度安排后续片段。
- 自定义预热范围、请求时长、间隔和流量上限。
- 在播放器缓冲不足时优先保障当前播放。
- 所有标签页共享请求和流量限制。
- 支持简体中文和英文，可跟随页面语言或手动选择。
- 在本地查看状态并按需导出诊断。

预热会额外使用网络流量；播放效果取决于网络路径、CDN 缓存行为和视频服务。扩展不切换播放器的 CDN，不更改 DNS 或路由设置。目前支持部分 DASH 点播视频的视频轨，不支持直播或音频预热。

扩展会向视频原本使用的受支持 CDN 发送媒体请求，其中包含哔哩哔哩提供的签名地址、片段字节范围及页面来源信息。诊断信息仅保存在本地，除非你手动导出并自行分享；没有开发者遥测或广告服务。

本扩展为独立工具，与哔哩哔哩、Mozilla 或 CDN 服务商没有官方关联。

兼容平台：桌面版 Firefox 142 及以上。

建议分类：视频、照片和音乐；其他。

许可证：MIT。

版本说明（0.2.0）：默认简体中文；按页面语言自动匹配及手动语言选择；显示版本号；新增图标；整理设置与诊断界面；添加隐私说明和发布元数据。
